Preserve existing panel visibility toggle and stock component styling/tokens. Electron has a fixed 300px nominal panel; GPUI's existing resize capability is retained, not claimed as an Electron behaviour.

Workspace integration now retains the sidebar's preferred rem-scaled width independently of properties. Double-click the resize divider to restore the 300px nominal default (18.75rem); double-clicking content is not a reset action. See workspace-integration.md for current tests and live evidence.

Header uses closest stock typography to the reference's 12px semibold label. Thumbnail preview is domain rendering; preserve aspect ratio, PDF content, annotation overlays and rotation. Each row has Page N then stock icon buttons for Set page scale, Rotate left and Rotate right. Buttons act on that row's page and do not bubble into duplicate row selection. Scale badges reflect existing page scale. Keyboard selection, focus, scroll-to-page, busy/error/empty/loading states and constrained widths belong to verification.
