Butter Paper

Butter Paper is a free, open-source, cross-platform alternative to Bluebeam Revu for PDF review and markup in architecture, engineering, and construction—available on macOS, Windows, and Linux.

Butter Paper is early-stage software. Expect rough edges, and please report bugs or workflow issues through GitHub Issues.
