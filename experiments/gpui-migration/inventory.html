Source-mapped inventory

UI contract, not a component count.

Each row records the behavior that a GPUI replacement must preserve. “Direct” means GPUI has an applicable rendering or input primitive. It does not mean Butter Paper receives the behavior for free. “Custom” means product-level implementation is required. “Proof” marks a migration gate.

Direct

Layout, painting, focus/action routing, images, virtual lists, scroll containers, and native windows provide useful foundations.

Custom

Nova styling, all compound controls, document chrome, domain tools, and many transient-surface semantics need Butter Paper code.

Proof required

Accessibility, IME, PDF transfers, high-frequency input, Windows, and packaging need real measurements and platform evidence.

Shortcut set observed in source

Application: Cmd/Ctrl+N, O, S, Shift+S, Z, Shift+Z, X, C, V, A. View: Cmd/Ctrl+=, -, 0, with Shift-routed application zoom behavior. Tools: V, hold Space, T, R, E, Shift+C, L, A, Shift+L, Shift+Alt+L, Shift+Alt+Q, Shift+Alt+A, Shift+N, Shift+P, P, H, C, K, Q, I, G.

The shortcut router suppresses tool shortcuts in editable, combobox, dialog, and related interactive contexts. Popover tool shortcuts close the popup before selecting the tool. These are behavior contracts, not only accelerator strings.
