Execution order

Static pixelsRequire exact flat fills and borders. Limit tolerance to text antialiasing, SVG edges, and PDF raster pixels after bounds match.
State atlasCapture normal, hover, keyboard focus, selected/open, disabled, dirty, loading, error, and minimum-window states per component.
BehaviorRun keyboard, pointer, focus return, shortcut arbitration, resize, virtual-list reuse, and multi-tab state checks.
AccessibilityInspect the AccessKit tree and screen-reader output. A visual match cannot pass a component with missing roles, names, state, order, or announcements.

Current recommendation

Continue component by component. The shell geometry is close enough to make regional pixel work efficient, but no component gate is complete. Use GPUI directly for layout, SVG, lists, images, scrolling, actions, and pointer events. Keep Butter Paper wrappers only where Nova styling or product semantics exist. Do not call a region “default GPUI”: GPUI 0.2.2 supplies framework primitives, not finished desktop widgets.
