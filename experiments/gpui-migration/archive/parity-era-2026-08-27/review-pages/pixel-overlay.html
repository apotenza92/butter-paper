Freeze deterministically or mask before scoring. Do not weaken the rest of the frame.

Required capture contract

  1. Capture Electron and GPUI on the same operating system, display, scale factor, theme and color profile.
  2. Use the same outer and content bounds. Record both dimensions in the filename or manifest.
  3. Use the same Geist font asset and font metrics. Wait for fonts and PDF detail surfaces to settle.
  4. Drive both apps to the same fixture state through deterministic actions.
  5. Compare the full frame, then inspect mismatching bounds by shell region.
  6. After visual parity, run keyboard, accessibility, IME, document-integrity and performance gates separately.
