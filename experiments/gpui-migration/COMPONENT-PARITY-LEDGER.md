# GPUI cutover, component, and feature parity ledger

This ledger tracks migration proof, not optimism. `Partial` means that some
behavior exists but the full Electron contract has not passed. A compilation
or unit test never counts as visible acceptance. Component rows prove reusable
building blocks only. They do not raise a document journey to complete.
